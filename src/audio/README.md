# src/audio

Drum one-shots loaded by `src/utils/audioSamples.ts`. Each music preset in
`src/domain/musicPresets.ts` looks up a file per slot (kick, hat, snare, clap,
perc) by matching **every** `sampleHints` keyword against the file name. If no
file matches, the engine falls back to the real-time Tone.js synth.

## Current files

These are generated by `npm run samples` (`scripts/generate-samples.mjs`) —
layered, enveloped synthetic one-shots, voiced per preset. They are committed so
the app has real samples out of the box; regenerate any time you tweak the script.

## Using your own samples

Drop `.wav`, `.mp3`, or `.ogg` files here whose names contain all the keywords
for a slot (see `sampleHints` in `src/domain/musicPresets.ts`) and they override
the generated ones automatically — e.g. a real recording named
`rave-kick.wav` replaces the generated `rave-kick.wav`. Keep one-shots short
(under ~0.6 s) so they don't overlap at fast tempos.
